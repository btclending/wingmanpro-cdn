# WingmanPro CDN Assets

Static assets for WingmanPro landing page, served via GitHub Pages CDN.

## Assets

| File | Size | Usage |
|------|------|-------|
| Hero_image.webp | 297 KB | Landing page hero background |
| Airplane_image.webp | 129 KB | Landing page airplane overlay |
| city-background.jpg | 589 KB | Auth pages background |
| logo-icon.png | 85 KB | Footer logo |

## Usage

Assets are available at:
```
https://raw.githubusercontent.com/[ORG]/wingmanpro-cdn/main/[filename]
```

Or via jsDelivr CDN:
```
https://cdn.jsdelivr.net/gh/[ORG]/wingmanpro-cdn@main/[filename]
```
